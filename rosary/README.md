# Rosary

A mobile-first, installable Rosary PWA. It presents a complete connected wooden Rosary, exact prayers, daily mysteries, direct bead selection, sequential navigation, offline support, and saved progress.

## Local development

```bash
npm run build
npm run preview
```

Open `http://127.0.0.1:4173/rosary/`.

## Quality checks

```bash
npm run check
```

## Deployment

GitHub Pages deployment is configured for `main`. Enable Pages with **GitHub Actions** as the source.
